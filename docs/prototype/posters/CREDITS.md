# Poster credits

These are public-domain film posters from Wikimedia Commons, shrunk to 400 pixels wide. They are used only in the throwaway prototype pages in the parent folder. In TV Mode the mockups borrow them as placeholders for invented shows, so a poster here does not mean the show named on the page is that film.

Author or source and licence tag are as the Commons file page gives them. Licence tags were checked against each page's wikitext on 2026-11-26.
